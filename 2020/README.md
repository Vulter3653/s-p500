# 2020

2020년 S&P 500 구성기업과 해당 기업의 10-K 자료를 관리하는 폴더다.

- 구성기업 확정 기준일: `2021-01-01`
- 기업 중복 제거 기준: SEC CIK
- 세부 표본 규칙: `../docs/sample-definition.md`
- 기업 목록: `sp500_companies.csv` - 500개 기업
- 종목 감사 목록: `sp500_securities.csv` - 505개 종목
- 생성 방법: `../docs/constituent-data-method.md`

2020년 적격 표본 445개가 처리되었고, 결과·R2 manifest·품질검사 파일은 읽기 전용으로 보존한다. 원본 HTML의 현재 보관 위치는 Google Drive다.
