# License and usage notes

Accessed 2026-07-29 from the official University of Notre Dame Software Repository for Accounting and Finance page.

The official page states that the dictionary and sentiment lists are free for academic research and directs commercial users to request a license. It does not explicitly grant public redistribution of the original or a complete derived word list. This project therefore records `research_use_permitted_redistribution_unclear`: the verified source file and full analysis-ready derivative remain local and are ignored by Git.

This is a conservative repository policy, not a legal opinion. Researchers must obtain the file from the official page and verify the recorded SHA-256.
