02 · MODEL SPECIFICATION

기본 회귀식

모든 핵심 모형은 text controls, event-aligned t−1 firm controls, Firm FE(αᵢ), Year FE(δₜ)를 포함한다. 추정은 statsmodels.api.OLS(...).fit(), 기본 covariance는 nonrobust이다.

Model 1G · 전체 AI 존재

CARᵢₜ = β₀ + β₁ AI_Mentionᵢₜ + γ′Tᵢₜ + θ′Fᵢ,ₜ₋₁ + αᵢ + δₜ + εᵢₜ

Model 1H · Section AI intensity

CARᵢₜ = β₀ + β₁ Section_AI_Focusᵢₛₜ + γ′Tᵢₜ + θ′Fᵢ,ₜ₋₁ + αᵢ + δₜ + εᵢₜ

Model 1I · 변화/최초 언급

CARᵢₜ = β₀ + β₁ ΔAI_Mentionᵢₜ + controls + FE + εᵢₜ
CARᵢₜ = β₀ + β₁ First_AI_Mentionᵢₛₜ + controls + FE + εᵢₜ

Model 1J · Start / Stop decomposition

CARᵢₜ = β₀ + βS StartAIᵢₜ + βT StopAIᵢₜ + γ′Tᵢₜ + θ′Fᵢ,ₜ₋₁ + αᵢ + δₜ + εᵢₜ

Model 1K · Start/Stop × AI_Focus

CARᵢₜ = β₀ + β₁StartAI + β₂StopAI + β₃AI_Focusₜ + β₄AI_Focusₜ₋₁ + β₅(StartAI×AI_Focusₜ) + β₆(StopAI×AI_Focusₜ₋₁) + controls + FE + ε

Model 1L · Section transition × language

Start: CAR = β₀ + β₁StartAIᵢₛₜ + β₂Mᵢₛₜ + β₃(StartAI×M) + controls + FE + ε
Stop: CAR = β₀ + β₁StopAIᵢₛₜ + β₂Mᵢₛ,ₜ₋₁ + β₃(StopAI×Mₜ₋₁) + controls + FE + ε

M은 Concreteness_AI, FutureFocus_AI, PastFocus_AI를 각각 별도 추정. Stop은 1→0과 Stay1(1→1)을 비교하고 moderator는 t−1 사용.

07 · PROFESSOR EMAIL EVIDENCE MAP

교수님께 보고한 세 가지 결과의 상세 근거

이 절의 목적은 새로운 결과를 추가하는 것이 아니라, 메일의 각 문장이 어떤 변수·표본·모형·회귀결과에서 나온 것인지 설명하는 것이다.

메일 1. 전체 10-K에서 이전 연도에 AI를 언급하지 않았다가 새롭게 언급하기 시작한 기업에서 음의 시장반응이 나타남.

전체 10-K · StartAI

Model 1J에서 StartAI와 StopAI를 동시에 포함한다. StartAI는 6개 CAR window에서 모두 음(-)이며, [-1,+1] β=-0.004578(p=.0127), [-2,+2] β=-0.004866(p=.0276), [-1,+2] β=-0.004451(p=.0287), [-2,0] β=-0.004533(p=.0105)이다. 대표적으로 [-2,0]에서는 NoChange보다 약 -0.453%p 낮다. 전체 StopAI는 유의하지 않다.

메일 2. Item 1A Risk Factors에서는 AI 공시를 새롭게 시작하는 경우 음의 반응, Item 7 MD&A에서는 기존 AI 언급을 중단하는 경우 일부 시장반응이 음(-).

Section별 Start / Stop

Item 1A. Model 1J StartAI는 CAR[-2,0] β=-0.003090(p=.0916), CAR[-1,+2] β=-0.003467(p=.0998). Model 1I First_AI_Mention에서는 CAR[-2,0] β=-0.003935(p=.0431), CAR[-1,+2] β=-0.004391(p=.0497)였다.

Item 7. StopAI는 CAR[-1,+1] β=-0.004634(p=.0481), CAR[-1,+2] β=-0.005125(p=.0467), CAR[0,+2] β=-0.004086(p=.0572). Item 7 StartAI는 뚜렷하지 않았다.

메일 3. Item 1 Business에서 AI 언급을 중단하는 경우, 중단 직전 Concreteness가 높을수록 시장반응이 더 낮아지는 방향. Past tense에서도 일부 음(-) 방향.

Item 1 · StopAI × language

Stop 모형은 1→0을 Stay1(1→1)과 비교하며 moderator는 t−1 값을 사용한다. AI-specific 언어변수는 AI가 없는 해에 0으로 채우지 않는다.

Stop×Concreteness_AI(t−1): [-2,+2] β=-0.03605(p=.0353), [-3,+3] β=-0.05524(p=.0062), [-1,+2] β=-0.03095(p=.0488), [-2,0] β=-0.03310(p=.0212); 6개 window 모두 음(-).

Stop×PastFocus_AI(t−1): [-1,+2] β≈-0.00601(p=.0308), [0,+2] β≈-0.00527(p=.0169). FutureFocus interaction은 전반적으로 뚜렷하지 않았다.

해석 한계. 여러 event window·section·transition·moderator를 탐색했으므로 nominal p-value만으로 확정적 결론을 내리지 않는다. Model 1L interaction은 엄격한 다중검정 보정 후 5% 수준에서 유지되지 않는다. 전체 Model 1J StartAI의 네 nominal p<.05 결과는 12개 focal coefficient family에서 BH-FDR 10% 수준(q≈.076–.086)에는 남지만 5%에는 남지 않는다. 따라서 현재 결과는 탐색적 패턴이며 primary event window는 아직 지정하지 않았다.
